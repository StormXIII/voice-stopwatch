# voice-stopwatch

纯静态网页秒表，支持键盘与中文语音控制。零依赖、零构建，双击即用。

## 功能

- **计时** — `Space` 开始/暂停切换，`清零` 按钮复位，状态栏实时反馈（准备开始 / 计时中 / 已暂停）
- **语音控制** — 中文语音监听，边说边识别（interim results），说完即触发，感知延迟约 0.3s
- **帮助弹框** — 右上角 `?` 按钮查看当前支持的语音指令；`Esc`、点击遮罩、`✕` 均可关闭；弹框打开期间 `Space` 不会误触计时器

## 语音指令

| 操作 | 识别词 |
|------|--------|
| 开始 | `开始` · `启动` · `继续` |
| 暂停 | `暂停` · `停止` · `停`（「停下」不触发） |
| 清零 | `清零` · `重置` · `归零` |

> 词表与页面内帮助弹框同源（`script.js` 中的 `VOICE_COMMANDS`），修改一处即全部同步。

## 快速开始

双击 `index.html` 即可使用。

- **浏览器**：Chrome / Edge 等 Chromium 系浏览器；不支持的浏览器会自动隐藏语音按钮，键盘与按钮操作不受影响
- **网络**：Safari 在本机完成识别，离线可用；Chrome 会将音频上传至 Google 服务器，需网络可达 Google——大陆网络不可达时提示连接失败，建议改用 Safari。隐私敏感场景请注意
- **麦克风**：首次开启语音需授权麦克风权限

## 技术实现

- 三文件纯静态（HTML / CSS / JS），无框架、无构建工具、无运行时依赖
- `interimResults = true` 实现低延迟触发；400ms 时间防抖 + 每句话去重标记，避免云端中间结果修正、final 确认导致同一指令重复执行
- 识别会话意外中断后 120ms 自动重连；错误分级提示（权限被拒 / 未检测到麦克风 / 网络不可用）

## 项目结构

```
├── index.html   页面结构、帮助弹框
├── script.js    计时逻辑、语音识别、弹框交互
└── styles.css   样式（暖白设计系统、语音脉冲动画）
```
